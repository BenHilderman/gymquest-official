# v4.3 Extras — locked spec

**Base:** Colift v4.3 design (already implemented).
**This doc:** the v4.2 ideas that survived audit and are layered on top of v4.3, plus the structural Feed rebrand.

Each section is **locked** — implementation can begin immediately.

---

## 0. Governing principle

After 27 individual decisions across the 4.2/4.3 audit, this rule emerged:

> **Entertainment surfaces deserve infinite content. Conversation and identity surfaces deserve quiet authenticity.**

What that means in practice:

| Surface kind | Examples | Backfill rule |
|---|---|---|
| Entertainment | feed, Stories, Discover | ✅ algorithmic backfill allowed (clearly labeled) |
| Identity | Profile, Activity, Year So Far | ❌ no algorithmic; ✅ rotation across own real data only |
| Conversation | DMs, Squad Chat, Comments | ❌ no bot speech, no Discover injection — quiet is honest |
| Router | Home Slot 1-4, Plus, Crews list | ❌ no content feed; ✅ context cues from real data only |

Every locked decision below is consistent with this rule.

## 1. Structural change — `feed` tab

### Rename + repositioning

- **Tab renamed:** "Friends" → **`feed`** *(lowercase, Gen-Z native per §1)*
- **Default behavior:** mixed feed (network priority, Discover backfill, clearly labeled)
- **Friends-only purity preserved as the `friends` filter chip**

### Filter chip set (4, principle-aligned)

| Chip | Default? | Behavior | Principles |
|---|---|---|---|
| `for you` | ✅ | mixed default — friends → crew → live → backfill, ranked by relevance | ENTERTAIN + IDENTITY |
| `friends` | — | strict v4.3 friends-only experience preserved as opt-in | SOCIAL |
| `live` | — | only people training right now (followed + same gym) | LIVE + ACTION |
| `near you` | — | same-gym posts + clubmates | SOCIAL + LIVE |

Drop: "just posted" (covered by ranking), "prs" (too narrow), "crew" (Crews tab handles it), "training now" (renamed `live`).

### Default ranking signal weights

`friends > live > clubmates > crew > Discover backfill`

Backfill cards labeled **"from your gym"** or **"you might like"**.

### Existing behaviors preserved

- Stories+Presence row at top
- Paper-airplane DM button on toolbar
- [feed] [activity] segmented control
- Pattern-interrupt cards every 9 posts ("1 year ago", "vs friends this week")

## 2. Discover backfill scope

### ✅ Backfill ON

- **Feed** mid-stream — labeled cards interleaved when network content thins
- **Stories caught-up transition** — when user has watched all friend stories, auto-flow into "from your gym" / "trending" stories. Skippable. *Single highest-engagement win — turns dead-end into infinite scroll.*
- **Stories row on Home/Feed when thin** — fewer than 3 friends with active stories triggers labeled backfill creator/trending bubbles

### ❌ Backfill OFF

- Crew Detail quiet states — *"this crew is quiet — be the spark"* beats faking
- Squad Chat quiet states — bot pollution kills the chat
- Profile rotating Pulse cards — identity stays stable
- Activity Pulse top card — covered by existing "today on Lift" empty state

## 3. Locked decisions — items 1-3 (early walkthrough)

### Item 1 — Discover Mini on Home (peek card)

Single small card at the very bottom of Home (below Identity Footer). Shows one Discover thumbnail + title + label "later, if you have time →". Refreshes once per day. No horizontal scroll, no animation, no badge.

### Item 2 — Slot 5 Day-of-Week Ritual *(v4.3 wins)*

Day-of-Week Ritual stays predictable: Mon goal / Tue tip / Wed mid-week / Thu Friday plan / Fri weekend / Sat events / Sun crew recap. **No Today's Pulse rotation. No internal rotation per open.** Habit > variability per design §4A.

### Item 3 — "your people today" slim strip on feed

Single 1-line strip above the Stories+Presence row, ~24pt height, text-only, no actions. Rotates one item per open from a strictly **friend-derived** pool:

- "5 of your friends did push this week"
- "your squad hit 87% of weekly goal"
- "you + daniel co-presence at goodlife wednesday"

Hides when no signal. Tap → relevant detail.

## 4. Locked decisions — items A-H + Crew Moments

### Item A — Squad Moments (slim rotating line)

**Where:** In a Squad detail view, between squad header and chat thread.

**Stat pool (3, real data only):**
1. Last co-presence moment ("you and marcus trained at goodlife · 2 days ago")
2. PRs this month ("squad PRs this month: 7")
3. Streak leader ("longest squad streak: sarah · 31 days")

**Rules:**
- Rotates one stat per open
- ~24pt height, no card chrome
- Hides entirely when squad has zero notable activity (no sad-empty stats)
- Tap → relevant detail
- "Tons lifted this year" *(vanity-gamification)* explicitly dropped

---

### Item B — Profile suggestions (single card at 0 posts, throwback rules)

**Where:** Own Profile, top of Posts area.

**Trigger:** User has zero posts.

**Card content:** One suggestion card at top of post grid:
- Picks the single strongest signal (best PR > longest workout > most recent workout)
- Tap → post editor pre-filled with that workout's data

**Throwback rules** (the post that gets created):
- ✅ Visible label: "throwback · 2 weeks ago" or "📅 from oct 14"
- ✅ Post timestamp = workout date (not now)
- ✅ Sorts to actual chronological place in profile grid (not top)
- ✅ Optional: user can attach a photo from photo library that already exists from that date — explicitly opt-in
- ❌ No fake "live capture" pretense
- ❌ Does NOT bump in friends' "just posted" filter or "for you" top
- ✅ Card disappears the moment user has 1+ posts (forever)

---

### Item C — Plus hero subtitle (humanlike check-in copy)

**Where:** Top of Plus tab, below the dumbbell hero icon.

**Format:** `day [N] · [check-in line]`

**Default rotation pool** (random per open, no fake hype):
- "let's get to it"
- "ready when you are"
- "another one"
- "back at it"
- "in for one"
- "what's the move today?"
- "you came back"
- "good to see you"
- "showing up for [your goal]" *(when goal is set)*
- "let's lift" *(fallback)*

**Context overrides** (swap when condition true):

| Condition | Line |
|---|---|
| User at saved gym | "you're here" |
| Hasn't trained today AND after 7pm | "still got time" |
| Streak ≥ 100 | "respect" |
| Streak ≥ 365 | "a year in" |
| First open after a PR session | "ride that PR" |
| First open ever (day 0 streak) | "let's start" *(no streak prefix)* |
| Day 1 streak | "day 1 · here we go" |
| Weekend (Sat/Sun) | "weekend lift" |
| Before 9am | "starting strong" |
| Returning after >7 days off | "welcome back" |

**Rejected explicitly:** "BEAST MODE" / "GRIND" / "let's go champ" / "crush it" / "the only bad workout..." — anything with all-caps, emoji walls, fake stakes, generic motivational quotes.

**Tone:** friend texting "you ready?" — not a coach yelling.

### Item D — Home Slot 4 Live Now Strip (always-on backfill line)

**Where:** Home Slot 4. Below the friend live-now strip, always rendered.

**Top strip:** live friends *(can be 0 — that's fine)*. Green presence rings preserved as "follow + live" trust signal.

**Bottom strip (always-on):**
- Section label: "from your gym · training your split now"
- 3-5 backfilled avatars
- **No presence rings** on backfilled avatars (visual demotion preserves friend-ring trust)
- Smaller avatars than friend strip
- Refreshes per open
- Tap → public profile (not a faked "live session")

---

### Item E — Profile Live State Line rotating (self-derived only)

**Default training-state lines (always priority):**

| State | Line |
|---|---|
| Training now | "in it · push · 32 min" |
| Trained today | "done for today · push · 64 min" |
| Trained yesterday | "last lifted yesterday · push · 64 min" |
| Trained 2-6 days ago | "last lifted [N] days ago · push · 64 min" |
| Trained 7+ days ago | "back tomorrow?" |
| Never trained | "let's start" |
| Rest day (recent + earned) | "rest day · earned" |
| Rest day (no recent) | "rest day" |

**Self-derived stat fills (only fill rest-day slot, only when threshold met):**

| Threshold | Line |
|---|---|
| Partner Mode 2+ sessions in 14 days | "you and [partner] lifted 3x this week" |
| Bench up ≥10 lbs over 30+ days | "bench up 15 lbs in a month" |
| Consistency ≥70% of weeks | "87% of weeks this year — consistent" |
| Streak crosses 7/30/100/365 | "day 17 going strong" |
| Volume up significantly month-over-month | "volume up 20% from last month" |
| First leg day this week (planned today) | "first leg day this week" |

**Rules:**
- Format stays factual, lowercase, brief
- Training-state always wins when applicable
- Stat fills only render when threshold met (no "bench up 0.5 lbs")
- Same humanlike tone as Plus hero — quiet check-in vibe

---

### Item F — Story Highlights "fresh" dot

**Where:** Profile (own), the Story Highlights row.

**Behavior:**
- Subtle 3-4pt dot at top-right corner of any highlight bubble that owner hasn't viewed in 30+ days
- **Owner-only** — other-user views never see the dot
- Disappears when the owner taps that highlight
- 30-day threshold (tunable later)
- No text label, no animation

---

### Item G — Crews tab rotating header line

**Where:** Top of Crews list tab, above the existing 6 sections.

**Pool (network + proximity facts only, NO algorithmic recs):**

*Network (when user has crews):*
- "your crew hit 87% of weekly attendance"
- "tonight in [crew name]: 3 going"
- "[friend] just joined [crew name]"

*Proximity (works even without crews):*
- "tonight at goodlife: 3 crews lifting together"
- "12 crews active near you"
- "crew event near you in 2h"

**Rules:**
- Single line, ~24pt, taps to relevant detail
- All factual counts/events — never "trending crew" or "you might like"
- Hides when no factual signal available
- Refreshes per open

---

### Item H — Slot 2 squad chat preview rotating

**Where:** Home Slot 2 squad card. Same v4.3 card structure (avatars + today's status + weekly goal bar + chat preview line + actions).

**Rotation pool for the chat-preview text line (real squad data only):**

| Facet | Example |
|---|---|
| Latest chat message *(default if fresh)* | `marcus: "wsg, legs tonight?"` |
| Latest workout-share system event | `marcus just crushed push · 17 sets` |
| Latest reaction in chat | `sarah reacted 🐐 to your push day` |
| Open poll | `poll: legs tonight? (3 of 5 voted)` |
| Squad streak | `squad streak: 17 days` |
| Today's training status | `4 of 5 trained today — close one` |

**Rules:**
- Latest fresh message *(last 4 hours)* always wins when present
- Rotation per open, stable while user is on Home
- All sources are real squad data — same standard as Item A
- The chat itself stays untouched (no bot pollution per v4.3 §6B) — only the preview slot rotates

**Pool (real crew data only, hides when empty):**
